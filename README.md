
# Strategy Pattern - Calculator

## Project Description
This project demonstrates the Strategy Design Pattern using a simple calculator written in Java.

The calculator supports three operations:
- Addition
- Subtraction
- Multiplication

## Design Pattern
The Strategy Pattern allows the calculator to switch between different mathematical operations at runtime without modifying the Calculator class.

## Project Structure
- OperationStrategy.java - Strategy interface
- AddStrategy.java - Addition strategy
- SubtractStrategy.java - Subtraction strategy
- MultiplyStrategy.java - Multiplication strategy
- Calculator.java - Context
- Main.java - Client

## Technologies
- Java 17
- IntelliJ IDEA

## How to Run
1. Open the project in IntelliJ IDEA.
2. Make sure JDK 17 is configured.
3. Open Main.java.
4. Run the main method.

## Expected Output
Strategy Pattern - Calculator
Addition: 15.0
Subtraction: 5.0
Multiplication: 50.0
